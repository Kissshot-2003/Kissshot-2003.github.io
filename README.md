# 洛橙 · 个人主页

纯静态个人主页，通过 GitHub Pages 发布。

在线访问：<https://kissshot-2003.github.io/>

## 站点文件

- `index.html` — 主页
- `404.html` — 自定义 404 页面
- `assets/style.css` — 样式
- `assets/app.js` — 交互脚本
- `assets/favicon.svg` — 站点图标
- `assets/avatar.png` — 自托管头像（不再外链 GitHub）
- `assets/og-cover.png` — 社交分享封面（1200×630）
- `assets/*.svg` — 项目配图
- `sitemap.xml` / `robots.txt` — 抓取引导
- `.nojekyll` — 告知 GitHub Pages 关闭 Jekyll 处理

> `_headers` 在 GitHub Pages 上不生效（仅 Netlify / Cloudflare Pages 支持）。
> 文件内已注明；若迁移到支持该文件的平台，规则会自动启用，届时需重新核对 CSP。

原始工程位于本地 `C:\通用工程\personal-site`，其 `public/` 目录即本站内容。
